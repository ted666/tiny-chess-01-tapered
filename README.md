Tapered-eval chess engine in 4 KB of Python. Practice gauntlet mean Elo 1,519 (t0 1,451 / t1 1,654 / t2 1,451), total spare 1,430 plies — clears the 1,365 prize gate. Features: incremental evaluation with middlegame/endgame tapered piece-square tables, transposition table, hash move, root move ordering, Zobrist hashing, quiescence search, null-move pruning, late-move reductions, principal-variation search, and check extensions. Single file, deterministic, no model calls.

## Run it

```sh
python3 main.py
```
